# 🚀 My Project

Un sito web statico e responsivo, progettato per offrire un'esperienza utente fluida con una navigazione intuitiva. Il progetto include pagine di presentazione, un modulo di contatto e una struttura pulita e modulare.

## ✨ Caratteristiche Principali

* **Design Responsivo:** Ottimizzato sia per dispositivi mobili che desktop.

* **Navigazione Dinamica:** Componente di navigazione gestito tramite JavaScript (`navbar.js`) per un'esperienza interattiva.

* **Struttura Modulare:** Stili e script separati per facilitare la manutenzione.

* **Pagine Dedicate:** Include sezioni specifiche come "About" e "Contact".

* **Dark Mode Fluida:** Inversione dinamica dei colori basata su variabili CSS, con transizioni morbide e salvataggio della preferenza nel `localStorage`.

* **Background Interattivo su Canvas:** Simulazione dinamica di particelle con attrazione gravitazionale basata sulla posizione del puntatore.

## 🛠️ Tecnologie Utilizzate

* **HTML5:** Struttura semantica delle pagine.

* **CSS3:** Stili personalizzati e layout (`style.css`).

* **JavaScript (Vanilla):** Logica di interazione lato client.

## 🚀 Come iniziare

Essendo un progetto basato su tecnologie web standard, non è richiesta alcuna installazione complessa.

1. Clona questo repository o scarica la cartella `my-project`.

2. Apri il file HTML principale (es. `index.html` o `about.html`) direttamente nel tuo browser web preferito.

3. *Opzionale:* Per testare funzionalità avanzate (come fetch API o moduli), si consiglia di avviare il progetto tramite un server locale (es. l'estensione "Live Server" di VS Code).
